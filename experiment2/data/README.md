# Data for experiment 2

## Tanner

The data in the folder ``Tanner`` is from the paper "Robust neurocognitive individual differences in grammatical agreement processing: A latent variable approach" [1-2] and can be downloaded [here](https://dataverse.harvard.edu/dataverse/AgreementIndiff). In the folder are two files, ``RSVP_300-500.csv`` and ``SPR_300-500.csv``, which contains the averaged EEG amplitude between 300 and 500 ms after word onset in RSVP and SPR reading paradigms respectively.
